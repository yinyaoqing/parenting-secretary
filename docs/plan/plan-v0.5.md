## 給審閱 AI 的說明

請以批判性審閱者身分審閱。五項開發原則見 v0.4，摘要如下：無顧問且所有內容須有可查核來源；第一階段完成 0–3 歲全部功能；架構承載到 18 歲；一人搭配 AI 以最小成本開發；照顧風格由問卷決定但不得覆寫安全層。

本版新增大量內容模組。請優先檢查：（a）每個新模組是否真的有 A 級或 C 級來源，還是只有 B 級連結；（b）哪些內容雖有來源但仍可能被視為診斷或醫療建議；（c）一人是否維護得了這個內容量。

## 3. 內容政策

沿用 v0.4 的內容授權三級制（A 可引用原文、B 只能連結、C 只敘述結論）、內容卡必備欄位、季度更新腳本。本版補充：

- **開放資料視為 A 級**：政府資料開放平臺資料集適用政府資料開放授權條款，可商業利用、須標示來源。
- **政策數字視為獨立類別**：集中放在一個遠端 JSON，每年 1 月與 7 月各查核一次（多數補助在 1 月調整，預防保健等在 7 月調整）。
- **B 級來源的使用上限**：每張卡最多一個 B 級連結，且 B 級連結不得是該卡唯一的內容。

### 5.17 口腔健康（新增）

- 長第一顆牙起使用含氟量 1000 ppm 以上牙膏，3 歲以下米粒大小、3 歲以上豌豆大小，每日至少兩次，刷後不漱口（衛福部口腔健康司與中華民國兒童牙科醫學會建議；查核 2026-10-05）。
- 未滿 6 歲每半年公費塗氟一次（口腔健康司）。
- 奶瓶性齲齒：不含奶瓶入睡（國健署兒童口腔保健原文）。
- 長牙時程表以國健署原文為準，不自寫。
- 第一次看牙建議時間以口腔健康司原文為準。
- 觸發：第一顆牙紀錄出現時推送刷牙與塗氟卡；每半年推送塗氟提醒。

### 5.18 視力與螢幕（新增）

- 國健署「護眼 123」：每年定期檢查視力 1–2 次；未滿 2 歲避免看螢幕，2 歲以上每日不超過 1 小時；每日戶外 2–3 小時，用眼 30 分鐘休息 10 分鐘（查核 2026-10-05）。
- 兒童預防保健含視力檢查時點，與 5.11 合併提醒。
- 可選「螢幕時間紀錄」，只記錄不評分。

### 5.19 用藥安全（新增，食藥署原文）

- 「五要五不」原文：不自行購藥給兒童、不自行停藥或調整劑量、不與果汁或牛奶併服等。
- 退燒藥：發燒應就醫，不自行購買退燒藥；兒童不使用阿斯匹靈等水楊酸類退燒（雷氏症候群）。
- 磨粉：非必要不磨粉；緩釋、腸溶、糖衣劑型不可磨；先詢問兒童專用劑型。
- 藥品保存與剩藥回收（食藥署原文）。
- 用藥紀錄功能只倒數醫囑間隔，不提供任何劑量表（R6）。

## 7. 提醒數學、技術架構、成本

沿用 v0.4 第 6、7 章（規則式安全網、無後端、本地 SQLite、Expo、通知可靠性、成本）。本版補充：

- **遠端內容 JSON**：內容卡、政策數字、時程表、開放資料快取皆放靜態網頁空間（GitHub Pages），APP 啟動時檢查版本號下載；無伺服器邏輯。
- **開放資料抓取**：由開發者本機或 GitHub Actions 每月抓取並轉為精簡 JSON 發布，APP 不直接呼叫政府 API，避免 API 變動與金鑰管理。
