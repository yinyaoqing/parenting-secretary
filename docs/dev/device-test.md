# 真機驗證清單（階段 0）

用 Expo Go 開 preview 頻道（docs/dev/release/expo-go-preview.png）。兩支手機各跑一次，最好一支 iPhone 一支 Android。
每項打 ✅ 或寫下問題；問題請附畫面名稱與操作步驟。

## A. 首次使用

- [ ] 歡迎頁：嬰兒床插畫完整顯示、不變形；「建立孩子的檔案」可按。
- [ ] 建檔第 1 步：出生日用系統選擇器（iOS 滾輪在列下方展開、Android 跳對話框）；早產兒開關打開後出現預產期；三步的右上小插畫顯示。
- [ ] 建檔第 2 步：選「產後護理之家」才出現預定出所日。
- [ ] 建檔第 3 步：「先跳過，用混合型預設」直接回首頁。
- [ ] 照顧風格：讀繪本封面顯示；直接選預設可到結果頁；逐題回答可上一題、可改用預設；最後一題按「完成」。
- [ ] 結果頁：六向度拉桿位置合理；「重新作答」回到問卷。

## B. 每天用

- [ ] 首頁第一天：沒有任何紀錄時顯示小熊卡，不顯示狀態格與今天列表。
- [ ] 標題列：日間有太陽雲朵、夜間有月亮星星，不擋到文字與按鈕。
- [ ] 一鍵記錄親餵、尿布後：出現「已記錄」提示，按「復原」該筆消失。
- [ ] 睡著了 → 狀態格變琥珀色「睡眠中」並計時；醒了 → 回到上次睡眠。
- [ ] 瓶餵、體溫、副食品、清醒趴臥、用藥：表單標題有小圖；「時間」列可選時間；－15 分等快捷鍵有效；儲存後首頁與紀錄列表時間正確。
- [ ] 體溫：未選部位時儲存會提示；選部位後顯示該部位發燒定義。
- [ ] 紀錄列表：日期籤切換；當日摘要數字正確；點一筆展開修正與刪除；刪除要再按一次確定。
- [ ] 修正紀錄：日期與時間選擇器可用；±5、±15 分有效；睡眠可清除或設定結束時間；「開始時間不能在未來」會擋。
- [ ] 夜間模式：首頁右上切換；設定頁三段切換；所有畫面文字可讀、無純白刺眼區塊。
- [ ] 安全網提醒：連續紀錄數筆餵奶後，把手機時間往後調 4 小時再開 APP，首頁出現琥珀橫幅與夜間插畫；「還在睡，稍後」後 30 分鐘內不再出現。

## C. 內容

- [ ] 內容頁：置頂「這個時期的孩子」有封面圖；篩選籤「安全」「發展」有效；安全區塊「全部 14 條」展開。
- [ ] 內容卡詳情：安全睡眠卡與月齡卡有封面圖；右上 AA 切三段字級，回首頁後字級仍套用；來源連結可開。

## D. 同步與交接（兩支手機）

- [ ] 配對：A 顯示配對 QR，B 掃描，B 顯示「已與 A 配對」；兩邊的裝置名稱正確。
- [ ] QR 交接：A 選「給 B」顯示 QR（多張自動輪播），B 掃描到全部後顯示合併結果；B 的首頁出現 A 的紀錄。
- [ ] 差量：A 按「對方已掃描完成」後再記一筆，再次交接只顯示 1 張、合併結果「新增 1 筆」。
- [ ] 同一個孩子：兩支手機各自建檔同一個孩子後交接，設定頁只剩一個孩子，紀錄合併在一起。
- [ ] 睡眠衝突：兩支手機都按「睡著了」再交接，合併後只剩一筆進行中。
- [ ] 傳檔 iOS：「分享交接檔」能選到 AirDrop，對方存到檔案後「匯入交接檔」能選到 .psync。
- [ ] 傳檔 Android：分享面板能選 Quick Share 或 LINE；對方從 LINE 存檔後匯入成功。
- [ ] 跨平台：iPhone 經 LINE 傳給 Android，匯入成功。
- [ ] 錯誤：未配對的手機匯入交接檔，顯示「兩支手機的配對金鑰不同」。

## D2. 時程

- [ ] 時程分頁：依出生日列出「現在可以去」「接下來 120 天」；項目的日期與兒童健康手冊一致。
- [ ] 「時間窗已過」可展開；資料來源連結可開。
- [ ] 紀錄列表：交接合併後一分鐘內的同類紀錄顯示「可能重複」。

## E. 設定

- [ ] 暫停模式開關狀態重開 APP 後保留。
- [ ] 字級三段切換，首頁與內容卡字級跟著變。
- [ ] 孩子列有插畫縮圖；「同步與交接」列可進入。

## F. 多孩子

- [ ] 設定頁「新增孩子」建第二個孩子（例如 10 歲）後，首頁自動切到新孩子；標題列名字旁出現下拉箭頭。
- [ ] 點名字開切換單，切回嬰兒後狀態格、內容、時程都跟著換。
- [ ] 10 歲孩子的首頁只剩睡眠、體溫、用藥；內容頁顯示「還在撰寫中」；時程頁多在「時間窗已過」。
- [ ] 設定頁點孩子列進編輯頁，改暱稱後儲存，標題列同步更新。
- [ ] 封存孩子後列表消失，紀錄仍在（取消封存需等之後版本）；封存唯一孩子後首頁回到歡迎頁。
- [ ] 一鍵記錄的提示包含孩子名字。
