# 真機驗證清單（階段 0）

用 Expo Go 開 preview 頻道（docs/dev/release/expo-go-preview.png）。兩支手機各跑一次，最好一支 iPhone 一支 Android。
每項打 ✅ 或寫下問題；問題請附畫面名稱與操作步驟。

## A. 首次使用

- [ ] 歡迎頁：嬰兒床插畫完整顯示、不變形；「建立孩子的檔案」可按。
- [ ] 建檔第 1 步：出生日用系統選擇器（iOS 滾輪在列下方展開、Android 跳對話框）；早產兒開關打開後出現預產期；三步的右上小插畫顯示。
- [ ] 建檔第 2 步：選「產後護理之家」才出現預定出所日。
- [ ] 建檔第 3 步：「先跳過，用混合型預設」直接回首頁。
- [ ] 照顧風格：讀繪本封面顯示；直接選預設可到結果頁；逐題回答可上一題、可改用預設；最後一題按「完成」。
- [ ] 結果頁：六向度拉桿位置合理；「重新作答」回到問卷。

## B. 每天用

- [ ] 首頁第一天：沒有任何紀錄時顯示小熊卡，不顯示狀態格與今天列表。
- [ ] 標題列：日間有太陽雲朵、夜間有月亮星星，不擋到文字與按鈕。
- [ ] 一鍵記錄親餵、尿布後：出現「已記錄」提示，按「復原」該筆消失。
- [ ] 睡著了 → 狀態格變琥珀色「睡眠中」並計時；醒了 → 回到上次睡眠。
- [ ] 瓶餵、體溫、副食品、清醒趴臥、用藥：表單標題有小圖；「時間」列可選時間；－15 分等快捷鍵有效；儲存後首頁與紀錄列表時間正確。
- [ ] 體溫：未選部位時儲存會提示；選部位後顯示該部位發燒定義。
- [ ] 紀錄列表：日期籤切換；當日摘要數字正確；點一筆展開修正與刪除；刪除要再按一次確定。
- [ ] 修正紀錄：日期與時間選擇器可用；±5、±15 分有效；睡眠可清除或設定結束時間；「開始時間不能在未來」會擋。
- [ ] 夜間模式：首頁右上切換；設定頁三段切換；所有畫面文字可讀、無純白刺眼區塊。
- [ ] 安全網提醒：連續紀錄數筆餵奶後，把手機時間往後調 4 小時再開 APP，首頁出現琥珀橫幅與夜間插畫；「還在睡，稍後」後 30 分鐘內不再出現。

## C. 內容

- [ ] 內容頁：置頂「這個時期的孩子」有封面圖；篩選籤「安全」「發展」有效；安全區塊「全部 14 條」展開。
- [ ] 內容卡詳情：安全睡眠卡與月齡卡有封面圖；右上 AA 切三段字級，回首頁後字級仍套用；來源連結可開。

## D. 同步與交接（兩支手機）

- [ ] 配對：A 顯示配對 QR，B 掃描，B 顯示「已與 A 配對」；兩邊的裝置名稱正確。
- [ ] QR 交接：A 選「給 B」顯示 QR（多張自動輪播），B 掃描到全部後顯示合併結果；B 的首頁出現 A 的紀錄。
- [ ] 差量：A 按「對方已掃描完成」後再記一筆，再次交接只顯示 1 張、合併結果「新增 1 筆」。
- [ ] 同一個孩子：兩支手機各自建檔同一個孩子後交接，設定頁只剩一個孩子，紀錄合併在一起。
- [ ] 睡眠衝突：兩支手機都按「睡著了」再交接，合併後只剩一筆進行中。
- [ ] 傳檔 iOS：「分享交接檔」能選到 AirDrop，對方存到檔案後「匯入交接檔」能選到 .psync。
- [ ] 傳檔 Android：分享面板能選 Quick Share 或 LINE；對方從 LINE 存檔後匯入成功。
- [ ] 跨平台：iPhone 經 LINE 傳給 Android，匯入成功。
- [ ] 錯誤：未配對的手機匯入交接檔，顯示「兩支手機的配對金鑰不同」。

## D2. 時程

- [ ] 時程分頁：依出生日列出「現在可以去」「接下來 120 天」；項目的日期與兒童健康手冊一致。
- [ ] 「時間窗已過」可展開；資料來源連結可開。
- [ ] 紀錄列表：交接合併後一分鐘內的同類紀錄顯示「可能重複」。

## E. 設定

- [ ] 暫停模式開關狀態重開 APP 後保留。
- [ ] 字級三段切換，首頁與內容卡字級跟著變。
- [ ] 孩子列有插畫縮圖；「同步與交接」列可進入。

## F. 多孩子

- [ ] 設定頁「新增孩子」建第二個孩子（例如 10 歲）後，首頁自動切到新孩子；標題列名字旁出現下拉箭頭。
- [ ] 點名字開切換單，切回嬰兒後狀態格、內容、時程都跟著換。
- [ ] 10 歲孩子的首頁只剩睡眠、體溫、用藥；內容頁顯示「還在撰寫中」；時程頁多在「時間窗已過」。
- [ ] 設定頁點孩子列進編輯頁，改暱稱後儲存，標題列同步更新。
- [ ] 封存孩子後列表消失，紀錄仍在（取消封存需等之後版本）；封存唯一孩子後首頁回到歡迎頁。
- [ ] 一鍵記錄的提示包含孩子名字。

## G. 時間軸、行程與範本（設計稿 4）

- [ ] 首頁點狀態格進「紀錄」，上方有「列表／時間軸／一週」切換；6 歲以上第三格是「課表」。
- [ ] 時間軸：睡眠畫成左側方塊（跨夜的從頂端開始），餵食、尿布等畫成右側圓點加文字，靠太近的不重疊；有紅色現在線。
- [ ] 點時間軸上的一筆開修正頁；改完回來位置跟著變。
- [ ] 3 歲以上的孩子時間軸只畫 06 到 22 時。
- [ ] 一週：7 直欄睡眠方塊與餵食圓點，底下是每天睡眠時數；點一欄跳到那天的時間軸（只限最近 5 天）。
- [ ] 右上角日曆鈕進「行程與範本」；設定頁也有入口。
- [ ] 範本開關預設關；打開時要先選起點。月齡只能選滿 6、9、12、18、24、36 個月。
- [ ] 事件起點三個：開始上托嬰、副食品開始、入園或入學。沒有日期的會提示去哪裡補，點了會開孩子檔案。
- [ ] 孩子檔案有「開始上托嬰的日期」「入園或入學的日期」，可清除；填未來日期時，範本列表寫「尚未到起點」。
- [ ] 沒選起點時不能新增作息範本；固定行程（托嬰、回診、課程等）不受起點影響，照常畫在時間軸。
- [ ] 6 個月以下的孩子新增範本，名稱含「餵」「奶」會被擋下。
- [ ] 「從這週產生」：有 3 天以上睡眠起訖紀錄時列出小睡與夜間睡眠；存檔後範本以虛線畫在時間軸；再產生一次會取代上一次的，自己建的不動。
- [ ] 新增行程：類型、星期、時間、時長、地點、提前提醒、開始與結束日期都能存；可以編輯與刪除。
- [ ] 課程填節次後，6 歲以上孩子的「課表」頁排成一到五 × 節次的格子。
- [ ] 有今天稍後的行程或服藥倒數時，時間軸上方出現「接下來」提示。
- [ ] 交接：A 手機新增或刪除行程，交接後 B 手機也一樣；結果訊息寫「更新行程 N 筆」。

## H. 如廁訓練（第一版唯一的任務）

- [ ] 滿 1 歲半到 6 歲的孩子，日間首頁出現「如廁訓練」入口；夜間模式不出現。
- [ ] 任務頁：準備度六項可勾選，重開 APP 後保留；心態、訣竅、小技巧與國健署原文一致；來源連結可開。
- [ ] 按「開始如廁訓練」後，首頁出現「坐小馬桶」；按下選結果，提示可復原。
- [ ] 任務頁顯示這 7 天的次數與各結果次數、最近 14 天的圓點；沒有百分比。
- [ ] 「先休息」顯示國健署「包回尿布等一、兩個星期後再試」原文；「完成了」後首頁入口消失。
- [ ] 練習紀錄出現在紀錄列表與時間軸；交接到另一支手機後任務狀態一致。

## I. 備份與資料

- [ ] 設定 › 資料：輸入兩次密碼產生備份檔，分享面板可存到雲端硬碟或傳給自己；記下加密花了幾秒（較舊的 Android 手機）。
- [ ] 在另一支沒配對過的手機建檔後匯入同一份備份，孩子、紀錄、行程、照顧風格都回來；再匯入一次不會重複。
- [ ] 密碼打錯時顯示「密碼不對」；把交接檔當備份匯入時提示去「同步與交接」。
- [ ] 封存孩子後，「已封存的孩子」列出他，按「取消封存」後回到孩子列表。
- [ ] 刪除全部資料：要輸入「刪除」才會執行；刪除後回到歡迎頁。

## J. 照顧者支持與暫停模式

- [ ] 首頁最下方「想聊聊嗎？」與設定頁「照顧好自己」都能進入。
- [ ] 打卡三題各選一項後顯示「今天已記下」；心情選「很難受」時專線立刻移到上方。
- [ ] 連續兩天心情選「很難受」後，首頁出現「最近好像很辛苦」卡片。
- [ ] 專線的電話鈕可直接撥號；官方頁面連結可開。
- [ ] 「請別人幫忙」：勾選後出現預覽，按鈕開系統分享，可傳到 LINE。
- [ ] 孩子出生第 14 到 20 天、第 42 到 48 天，首頁各出現一次邀請卡，點過就不再出現。
- [ ] 打開暫停模式後，首頁出現「暫停模式中」，安全網橫幅、如廁訓練、照顧者邀請都不出現；紀錄按鈕與安全內容照常；按「恢復」後回來。

## K. 本地通知（Expo Go 可測）

- [ ] 1 歲以下孩子的首頁出現「允許通知」卡，按「允許」後系統詢問權限。
- [ ] 設定 › 提醒四個開關可切換；設定 › 通知健康檢查顯示權限、接下來的提醒。
- [ ] 記一筆餵奶後，健康檢查頁出現一則「距上次餵奶已…」的安全網提醒，時間是上次餵奶加上平常的間隔（最多 3 小時）。
- [ ] 記用藥並填間隔 4 小時，出現「間隔到了」提醒；文字有「APP 不建議劑量」。
- [ ] 新增一筆行程、提前 15 分，出現對應提醒；刪除行程後提醒消失。
- [ ] 把 APP 關掉或鎖螢幕，提醒仍準時跳出；點通知會開 APP 的對應畫面。
- [ ] 「送一則測試通知」：APP 留在前景，10 秒後跳出，準時度有數字。連測幾次，中位數小於 60 秒。
- [ ] 打開暫停模式後，健康檢查頁顯示「暫停模式中」，接下來的提醒變成 0 則；恢復後回來。
- [ ] 交接匯入另一支手機的餵奶紀錄後，安全網提醒時間跟著更新。

## 已知尚未處理

- 點 LINE 裡的 .psync 直接用 APP 開啟（需 development build）。
- 國外紀錄回國後的日期切分。
- 準時的鬧鐘權限（Android 12 以上 SCHEDULE_EXACT_ALARM）要等正式安裝版；Expo Go 下省電模式可能延後幾分鐘。
- 同步到手機行事曆：expo-calendar 不支援 Expo Go，需 development build。
- 從學校課表匯入（拍照或貼上文字）。
- 時間軸長按空白處補登。
