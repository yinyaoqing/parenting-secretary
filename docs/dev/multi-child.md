# 多孩子切換機制（規劃，2026-10-06）

情境：同一個家庭同時有 10 歲與 2 歲的孩子，或多胞胎。目標是一支手機、一個 APP，隨時切換「現在在看誰」，而且每個孩子的紀錄、時程、內容、提醒互不混淆。

## 現況盤點

已經是多孩子的：資料層所有表都以 child_id 為根（events、style_profiles、reminders、schedule_items）；建檔可以重複執行；交接包會帶全部孩子，合併引擎會把兩支手機各自建的同一個孩子收斂成一筆。

還不是多孩子的：首頁、內容、時程三個分頁都寫死 `listChildren()[0]`；設定頁孩子列只能看不能選；沒有「目前孩子」的狀態；提醒與安全網只算第一個孩子。

## 設計

### 1. 目前孩子（active child）

- settings 新增 `activeChildId`。沒有或指到已刪除的孩子時，退回第一個孩子。
- 以 context（ChildProvider）提供 `{ children, active, setActive }`，和主題一樣全域共用，切換後所有分頁立即跟著換，不需要各自重抓。
- 交接匯入後若新增了孩子，不改變目前孩子。

### 2. 切換的入口

- 首頁標題列的孩子名字變成可按：點開「孩子切換單」（底部抽屜），列出每個孩子的暱稱、月齡、縮圖，最後一列「新增孩子」。只有一個孩子時名字不顯示下拉箭頭，點了也直接進新增。
- 內容與時程分頁的標題列同樣顯示目前孩子，點名字開同一個切換單。
- 設定頁「孩子」區塊：每列可點，進入編輯頁（暱稱、出生日、預產期、餵養方式、地點、情境），並有「設為目前」與「刪除」（刪除要二次確認，事件一併墓碑化，不真的清除）。

### 3. 每個孩子各自的東西

| 項目 | 做法 |
|---|---|
| 紀錄與狀態格 | 依目前孩子查詢；一鍵記錄寫入目前孩子 |
| 安全網提醒 | 每個孩子各算一條，橫幅上標孩子名字；2 歲與 10 歲的孩子都會超過上界，但 1 歲以上不啟用安全網（現有規則），所以只會對嬰兒出現 |
| 內容卡 | 依目前孩子的月齡；10 歲的孩子超出目前內容範圍（0 到 3 歲），內容頁顯示「這個年齡的內容還在撰寫中」，安全內容照常 |
| 時程 | 依目前孩子的出生日；10 歲的孩子會落在「時間窗已過」，流感疫苗仍每年顯示 |
| 照顧風格 | 每個孩子一份（現有設計），切換單上不顯示 |
| 日夜模式、字級、暫停模式 | 跟手機走，不分孩子 |
| 交接與同步 | 不變，交接包本來就含全部孩子 |

### 4. 不同年齡層的呈現

- 月齡文字：2 歲以下用「N 個月」，2 歲以上用「N 歲 M 個月」，6 歲以上只顯示「N 歲」（age.ts 已可處理，只差 6 歲以上的簡化）。
- 10 歲的孩子首頁：餵奶、尿布、睡眠的一鍵按鈕對他沒有意義。規劃文件的 18 歲架構留了課表、服藥、復健等事件型別，但第一階段只做 0 到 3 歲。先做最小處理：3 歲以上首頁隱藏餵食與尿布區塊，保留體溫、用藥、睡眠，並顯示一行「3 歲以上的功能在之後的版本」。

### 5. 避免記錯孩子

- 切換單選了之後，首頁標題列短暫高亮，狀態格數字會明顯不同。
- 一鍵記錄的復原提示加上孩子名字：「已記錄 小米 濕尿布」。
- 時間軸與交接合併結果都按孩子分組顯示。

## 工程範圍與順序

1. ChildProvider 與 activeChildId（半天）。
2. 首頁、內容、時程改讀 provider；標題列可點與切換單（半天）。
3. 設定頁孩子編輯頁、設為目前、刪除（半天）。
4. 3 歲以上的首頁精簡與月齡文字（半天）。
5. 復原提示與合併結果加孩子名字（1 小時）。

合計約 2 天，不需要 development build，Expo Go 可測，不改任何原則與紅線。資料層不需要遷移。

## 需要你決定

- 10 歲孩子的首頁要「精簡」（隱藏餵食尿布）還是「完整」（全部按鈕照舊，由家長自己不用）。建議精簡。
- 切換單要不要支援「多胞胎同時記錄」（一次按下對兩個孩子都記一筆）。規劃文件 5.23 寫多胞胎「每個孩子獨立紀錄與提醒」，建議第一版不做同時記錄。
