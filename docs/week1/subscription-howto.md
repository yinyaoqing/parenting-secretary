# 訂閱流程（法規異動與機關新聞）

兩種機制：RSS 閱讀器（主力）與電子報（備援）。全部用你自己的帳號與信箱。總共約 30 分鐘。

## 一、準備一個 RSS 閱讀器

任選一個，手機與電腦都能看的為佳：Feedly、Inoreader、NetNewsWire（Mac 與 iOS 免費）、Feeder（Android）。建立一個資料夾叫「育兒秘書來源」。

## 二、機關新聞 RSS（直接加入閱讀器）

| 機關 | RSS 入口 | 要訂的頻道 |
|---|---|---|
| 國健署 | https://www.hpa.gov.tw/Pages/List.aspx?nodeid=1348 | 本署新聞、本署公告 |
| 疾管署 | https://www.cdc.gov.tw/RSS | 新聞稿、致醫界通函（疫苗時程變動常先出現在這裡） |
| 衛福部 | https://www.mohw.gov.tw/cp-2661-6125-1.html | 新聞 |
| 食藥署 | 食藥署網站首頁底部 RSS | 本署新聞 |
| 勞動部 | 勞動部網站 RSS 頁 | 新聞稿 |
| 教育部 | 教育部全球資訊網即時新聞 RSS | 即時新聞 |
| 社家署、財政部、口腔健康司 | 網站若無 RSS，改用三的電子報或四的網頁監看 | |

做法：打開入口頁，複製頻道的 RSS 網址，在閱讀器按「新增訂閱」貼上。

## 三、法規異動

全國法規資料庫沒有「單一法規」的異動推播，提供的是全站電子報與最新訊息。做法分兩層：

1. 訂閱全國法規資料庫電子報：https://law.moj.gov.tw/ 首頁「電子報訂閱」，填信箱。電子報每週列出新發布與修正的法規，掃一眼關鍵字即可。
2. 法務部 RSS：https://www.moj.gov.tw/lp-36-001.html 可加入閱讀器。
3. 補強：在閱讀器或網頁監看工具（例如 Visualping、Distill，免費方案即可）對下列法規的全國法規資料庫頁面設「內容變更時通知」，每週檢查一次：
   - 性別平等工作法 https://law.moj.gov.tw/LawClass/LawAll.aspx?PCode=N0030014
   - 戶籍法
   - 道路交通管理處罰條例
   - 小型車附載幼童安全乘坐實施及宣導辦法 https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=K0040038
   - 個人資料保護法
   - 食品安全衛生管理法
   - 醫療器材管理法
   - 勞動基準法

全國法規資料庫每週五更新，所以監看頻率設每週一次就夠。

## 四、沒有 RSS 的頁面：網頁監看

對下列頁面設內容變更通知（同上工具）：

- 國健署兒童預防保健服務頁、兒童發展篩檢頁
- 疾管署現行兒童預防接種時程表頁
- 社家署育兒津貼與托育補助頁
- 教育部 2–5 歲育兒津貼頁
- 財政部幼兒學前特別扣除額說明頁
- 口腔健康司塗氟頁
- 衛福部醫事司急救責任醫院名單頁

## 五、把通知變成工作

- 閱讀器每週固定一天掃一次，看到與數值來源表或政策 JSON 相關的變動，就在開發看板開一張「來源變動」卡，附連結。
- 每季（1、4、7、10 月）的政策查核以看板上累積的「來源變動」卡為起點，而不是從零重查。
- 疾管署的腸病毒、流感、登革熱新聞稿不只是來源更新，也是「季節提醒」的觸發來源；上線後由 GitHub Actions 自動抓同一個 RSS，人工訂閱是備援。
